# Cicero TTS

**Historical archive — no longer actively developed.**
*Archive historique — ce projet n'est plus développé activement.*

Cicero is a small, fast and free text-to-speech engine for French (and some
English), written in Python by Nicolas Pitre and Stéphane Doyon between 2003
and 2008. It converts text to phonemes using context-sensitive rules and
relies on MBROLA to produce audio.

This repository preserves the last release, 0.7.2 (June 2008), imported from
the original tarball, which is also attached to the v0.7.2 release.
